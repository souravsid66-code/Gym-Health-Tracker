# 🏋️‍♂️ Smart Gym Health Tracker

An automated tool built with **Python, Pandas, and NumPy** to help gym owners analyze member health data and generate visual reports.

## ✨ Features
- **Automated BMI Calculation**: Uses NumPy for high-speed health metrics processing.
- **Data Categorization**: Automatically flags members as 'Normal' or 'Overweight'.
- **Visual Analytics**: Generates Pie Charts using Matplotlib for business insights.
- **CSV Reporting**: Saves a final processed report for the gym owner.

## 🛠️ Tech Stack
- Python 3.x
- Pandas (Data Handling)
- NumPy (Mathematical Logic)
- Matplotlib (Visualizations)

## 🚀 How to Run
1. Clone the repo: `git clone <your-repo-link>`
2. Install dependencies: `pip install pandas numpy matplotlib`
3. Run the script: `python fitness_tracker.py`
